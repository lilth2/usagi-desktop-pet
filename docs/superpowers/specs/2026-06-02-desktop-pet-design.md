# 桌面桌宠应用 - 设计文档

**日期**: 2026-06-02
**范围**: 最小版本

## 概述

使用 PyQt5 + QPainter 矢量绘图构建一个 Windows/Mac 透明无边框桌面桌宠应用。宠物为蓝绿渐变果冻史莱姆，支持 Idle、Walk、Grabbed 三种状态，活泼好动型行为节奏。

## 技术栈

- Python 3
- PyQt5（图形界面 + 动画驱动）
- 单文件架构（`desktop_pet.py`）

## 窗口设计

- 继承 `QMainWindow`
- 属性：
  - `Qt.FramelessWindowHint` — 无边框
  - `Qt.WindowStaysOnTopHint` — 置顶
  - `WA_TranslucentBackground` — 透明背景
  - `Qt.Tool` — 不在任务栏显示（可选）
- 窗口大小：200x200（容纳 120-150px 宠物 + 浮动空间）
- 默认启动位置：屏幕右下角
- 鼠标事件：`mousePressEvent` / `mouseMoveEvent` / `mouseReleaseEvent` 实现拖拽

## 角色外观（QPainter 绘制）

### 正常形态
- **身体**：椭圆/水滴形主体，蓝绿渐变填充（`QLinearGradient`），约 80% 不透明度
- **高光**：左上角白色半透明小椭圆
- **眼睛**：两个黑色圆形眼珠，间距约 25px
- **嘴巴**：`drawArc` 绘制的微笑弧线
- **投影**：底部深色半透明扁椭圆

### 抓起形态
- 身体缩小到 70%，呈更圆的团状
- 眼睛变为 X_X（十字线）
- 嘴巴变为波浪线

## 状态机

由 `QTimer` 驱动，间隔 40ms（25FPS）。

### Idle（默认）
- 身体 Y 轴正弦浮动，周期 2s，幅度 8-10px
- 呼吸缩放：宽高 ±5% 正弦变化
- 眨眼：每 2-4s 随机触发，两阶段（80ms 闭眼 → 立即睁开）

### Walk
- 触发间隔：随机 3-8s
- 行走时长：随机 2-5s
- 水平移动速度：每帧 3-5px
- 方向随机，碰屏幕边缘掉头
- 行走时身体左右微摇 + 压扁拉伸形变
- 走完后自动切回 Idle

### Grabbed
- 左键按下时切换
- 身体缩至 70%，跟随鼠标
- 眼睛 X_X
- 松开后回 Idle

## 右键菜单

- 退出程序（主要功能）

## 状态切换规则

```
Idle --[定时器超时]--> Walk --[行走结束]--> Idle
Idle --[鼠标按下]--> Grabbed --[鼠标松开]--> Idle
Walk --[鼠标按下]--> Grabbed --[鼠标松开]--> Idle
```

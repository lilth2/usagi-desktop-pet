## 3. 处理规则与最终映射

- 使用可重复的确定性裁切、遮罩和等比 Lanczos 缩放；不生成表情、肢体、道具或新动作。原图中的真实遮挡保留。
- 白底素材通过闭合「分割遮罩」中的小轮廓缺口，再从外部泛洪分离背景。闭合只作用于遮罩，不补画原图。保留被黑色轮廓包围的白色身体，避免白色身体被删除。
- 7.png 用手工轮廓遮罩只提取中间角色，保留原有夜景光色和脚边草地。低分辨率及遮挡无法恢复，不能当作高清完整脚部素材。
- 画布统一320×320，脚底/枕头/接触面基线 y=280；按角色头部实际宽度约180px统一视觉尺度。完整保留耳朵、脚、手机、枕头/被子（原照片可见部分），不把整张照片强行压成正方形。
- 普通源图头宽230px，晚间手机375px，睡觉380px，夜景约110px；裁切位置、缩放系数、最终 alpha 边界详见 `asset-inventory.json`。
- 桌面画布110×110，窗口120×120，留出摇摆与浮动余量。绘制围绕同一脚底基线等比变换；外观切换0.3秒交叉淡入淡出。不同姿势的纵向高低差属于卧姿/立姿自然差异，不强制同高。
- 提供的是独立PNG照片，没有同一动作连续帧，故不存在逐帧居中处理。走路采用同一素材连续平移，拖拽缩小采用相同基线，避免人工帧抖动。

## 4. 时间表、问候和睡眠兼容

电脑本地时间每秒重新计算；不使用固定时区，不修改电脑系统时间。所有边界包含开始、不包含结束。

| 问候 | 时间 |
|---|---|
| 早上好 | 06:00–11:00 |
| 中午好 | 11:00–14:00 |
| 下午好 | 14:00–18:00 |
| 晚上好 | 18:00–次日06:00 |

| 外观 | 时间 |
|---|---|
| 午睡 | 12:30–14:00 |
| 夜间睡眠 | 23:00–次日06:00 |
| 晚间清醒 | 18:00–23:00 |
| 普通 | 其余时间 |

优先级为睡觉 > 晚间 > 普通。默认两张深夜图按日期轮换，可在设置固定为1或7图；不按动作随机抽图。深夜资源硬性限制在18:00–次日06:00；夜间睡眠配置不能越入白天。午睡可调或关闭，自动外观可整体关闭。

问候按本地日期 + 稳定时段ID去重并持久化，重启不重复。跨午夜进入新的本地日期后有独立记录。睡觉时只保留当前时段的一条待发送问候，交互或睡醒再发；错过时段不补发。关怀排在待发送问候前，已有气泡未结束时排队，不叠多个窗口。重要关怀可暂用普通吉伊卡哇，10秒结束后恢复该时刻的外观。睡眠不停止原关怀定时器和菜单设置。

右键 → **陪伴与时间设置…**：陪伴 / 外观时间 / 时间问候三个页面。可调整开关、午睡和夜间时间、晚间开始时间、问候各段开始/结束及文案。多条文案用「｜」分隔；保存会检查全天覆盖/重叠和问候名称，错误保留原配置并显示原因。

仅源码开发环境 `CHIIKAWA_DEV=1` 支持 `--preview-time 2026-10-19T23:00` 和开发预览页；打包版无法开启时间预览。预览不写入真实问候记录。

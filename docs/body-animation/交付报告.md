## 比例、位置和安全边距

- 显示画布统一320×320，底部接触基线 y=280；桌宠透明窗口仍为120×120，绘制画布仍为110×110。
- 先按可见头部轮廓等比缩放，再统一头部横向中心到x=160，目标头宽约140px。为带电脑的画面预留左侧空间，完整保留显示器底座和键盘，不用剪掉道具换取居中。
- 位姿本身的差异保留：卧姿和睡姿不拉成站立。不同姿势的脸部高度可以合理不同，窗口位置、基线和角色横向锚点保持稳定。
- 电脑和角色一起等比变换，没有拉长、压扁。静态图集和所有动画帧共享坐标；控制点、蒙版和面部保护范围也使用同一配准变换。
- 整图变换由现有QPainter外层控制；身体变化来自图集内部的局部网格，两者不会互相覆盖。减少动画时关闭身体、摇摆和点击跳动，停止周期性散步；拖拽反馈、通知和设置继续可用。

## 实现方式和源文件

采用连续局部网格变形离线烘焙为逐帧透明PNG图集，沿用原项目的PyQt5/QPainter绘制。每个动作32帧，七个角色共20份图集（640帧）。不是一张静图套统一transform：手臂围绕实际肩部连接位置转动，耳朵、身体、脚部有不同的局部影响区域；面部核心区域固定。

连续变形不把关节剪开，所以没有通过补洞拼接分层肢体。保留的源文件包括：

- `assets/chiikawa/animation_sources/<资源>/input-before-registration.png`：配准前输入；
- `rig-author.json`：可编辑的原始控制点、支点、作用范围和幅度；
- `source.png`：最终统一坐标透明源图；
- `rig.json`：与最终源图对应的派生控制点和配准参数；
- `masks/`：耳朵、手臂、身体等影响范围的灰度蒙版；
- `assets/chiikawa/processed/animations/manifest.json`：图集、帧数、时长和循环方式；
- 同目录的20份PNG图集：实际运行资源。

插值使用预乘Alpha，减少半透明边缘黑白残色；身体内部透明度修正为完全不透明。连续网格共享位移场，面部有固定保护区，动作幅度克制。互动与开心动作首尾均回到同一中性帧；待机/呼吸采用周期采样，不突然复位。

修改动作后运行：

```powershell
.\.venv\Scripts\python tools/author_body_animation.py
.\.venv\Scripts\python tools/capture_body_runtime.py
.\.venv\Scripts\python -m unittest discover -s tests -v
.\build.ps1
```

`tools/prepare_assets.py`也会进入新流程，不会用旧场景卡片覆盖新透明素材。运行只用本地PyQt5，不需要NumPy、Pillow、网络或付费API；NumPy/Pillow仅用于开发烘焙和预览。

## 三种模式与原功能

设置入口：**右键 → 陪伴与时间设置… → 陪伴 → 动画效果**。

- **仅整图动画**：新透明素材配合原有摇摆、呼吸式整体缩放、点击弹动、拖拽和移动；不播放身体图集。
- **整图＋身体动画**：默认；外层整体动作和局部身体动画叠加。
- **减少动画**：关闭非必要身体与整体运动，保留拖拽、点击关怀、菜单、设置和定时提醒。

切换动画模式不会重置当前手动选择的图片，也不改变窗口大小、点击区域或位置。模式存入现有兼容配置目录 `%APPDATA%\UsagiPet\settings.json` 的新增字段 `animation_mode`，保留其他字段与问候去重记录，保存前仍有 `.json.bak`。

保留了此前全部实际功能：透明置顶、左键拖拽/70%抓起反馈、双击按时段切图与关怀、限定散步、10句本地关怀、30分钟使用提醒/5分钟空闲重置、菜单预览/开关/退出、时间问候去重、外观时段和设置。聊天此前已移除，本轮保留的是现有本地文案关怀，没有虚构新的聊天历史、托盘或声音功能。

## 限制与产物

- 不是专业人工逐帧长篇动画；位移幅度以小型桌宠自然、克制为准。3图提供脚部交替反馈，尚非完整步态骨骼系统。
- 原图被电脑或草地挡住的解剖结构无法从原图恢复；仅做已标注的最小轮廓修复，不伪造完整脚。
- 7图为低分辨率参考，抠图用了生成模型，原有夜间光色保留，部分细节可能重描。
- 未进行真实双显示器硬件拖动、真实硬件休眠测试；时间跳变、睡眠外观兼容采用注入测试，限制如前。
- 独立程序：`dist/ChiikawaPet.exe`。最终构建、资源核验和启动检查见 `build-result.json`。
- 本地素材包：`deliverables/Chiikawa-body-animation-assets.zip`，包含透明图、图集、控制源、预览和报告。原始照片及个人配置备份不上传、不打包。

# 1.01 气泡布局修正

气泡优先贴近角色左侧，空间不足时放到右侧；两侧都不合适才用上方或下方。保留指向角色的尾巴，不再默认压在头顶。

静态轮廓外预留8个逻辑像素的动作安全区，气泡与安全区间留4个逻辑像素间距。常见姿势的实际距离约12–14个逻辑像素，保持贴近而不遮挡。计算包含正在淡出的旧图片，避免切图时挡住旧姿势；不追随每帧呼吸摇摆，因此不会细微抖动。靠屏幕边缘时只沿不影响分离关系的轴调整位置。

气泡在右侧时，小爱心显示在角色左侧；关闭气泡保留小爱心的位置和动画状态。气泡大小、原文、跟随、关闭和提醒逻辑不变。

77项源码测试通过。新增/扩展原生Qt测试，以实际绘制的角色和气泡像素区域验证七张素材、互动/开心/行走、放大与上浮、四角、长文本、小爱心及淡入淡出没有相交。另验证呼吸时气泡位置固定、间距不过远、关闭右侧气泡时角色截图不变。

Windows安装后的程序和两个macOS架构均进行打包应用自检，新增bubble_does_not_cover_pet检查。安装包仍为1.01修正版，安装内部版本号1.0.1；新校验结果和哈希见builds.json。没有进行用户实机、多显示器、混合DPI或真实休眠唤醒的硬件测试。

实际效果见head-pat.png。原配置和历史数据不变。

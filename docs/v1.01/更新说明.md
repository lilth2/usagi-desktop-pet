# 1.01 · 摸摸头回应

后续气泡遮挡修正与77项验证见[气泡布局修正](气泡布局修正.md)。

单击角色，等待系统双击判定结束后，头旁出现一颗粉色小爱心，播放当前素材已有的互动动画，并显示“收到你的摸摸啦。”

- 双击继续轮换全部7张并显示关怀语，不额外触发摸摸；拖拽不触发摸摸，并取消尚未确认的单击。
- 不换基础图片、不移动桌宠、不推进自动或手动关怀文案、不重置五分钟时钟。
- 重要提醒不被覆盖，摸摸文案延后；连续摸摸只保留一条当前反馈。
- 小爱心约1.1秒后消失，使用Qt矢量绘制，不新增角色素材或轮播调度器。
- 减少动画模式显示静态小爱心；睡觉姿势沿用已有慢呼吸，不生成不存在的动作。
- 关闭气泡不换图、不改变动画或计时，气泡内部点击不触发摸摸。
- 单击用于固定摸摸回应，不额外推进睡眠期间的自动问候；自动问候在睡眠结束后处理。

72项源码测试通过。新增6项原生Qt测试覆盖准确文案、动画和心形、双击取消、拖拽取消、重要提醒优先、减少动画和心形消失、关闭按钮不误触。旧设置测试改为受控空闲时间，避免电脑真实空闲超过5分钟时干扰断言。

Windows安装后应用自检通过，安装与卸载退出码0，说明书随安装写入，个人配置保持不变。Apple Silicon和Intel均在macOS15.7.9原生构建并启动自检，新增pat_response检查通过，包括心形绘制后的窗口像素变化。用户实机、多显示器、混合DPI及真实休眠唤醒未实测。

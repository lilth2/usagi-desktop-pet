# 双击关怀与小气泡

双击仍切换全部7张图片，同时弹出当前时段关怀语。手动关怀独立按「原创→辅助A→原创→辅助B」轮播，不推进自动问候文案，不改变五分钟截止时间；右键“一句暖心话”共用此入口。主动操作在关闭自动问候或免打扰时仍有反馈，自动问候继续受原开关和睡眠免打扰控制。

快速双击只更新现有普通气泡，重置其8秒显示时间；重要提醒不被覆盖，最多保留一条最新手动关怀待其结束。关闭气泡清掉待发关怀，图片、动画、手动/自动文案进度与五分钟时间保持不变。

气泡宽度随文字收缩，当前120×120逻辑像素桌宠对应上限168像素宽；最小高度46、最大高度136，常见主文案实测168×71。取消独立关闭按钮行和原80像素最低高度，字号11像素、紧凑留白、小关闭按钮、奶油粉色轻描边。长文本换行和内部滚动，关键功能消息不裁掉。

气泡尾巴随上/下/左/右摆放朝向角色。根据当前静态角色素材的透明轮廓定位，贴近真实角色而非大块透明画布；轮廓缓存，不跟随逐帧身体动画抖动。保留实时跟随、屏幕边缘避让、不抢焦点、可点击关闭、隐藏/恢复。

62项测试通过，包括所有七图轮播、双击出语及独立文案进度、免打扰下主动反馈、快速双击不积压、重要提醒优先、关闭与气泡鼠标事件隔离、小气泡尺寸、长文本滚动、静态轮廓锚定，以及原有动画/配置/提醒/设置回归。原生Qt抓图见pet-and-bubble.png、bubble.png；预览背景为中性底色，由真实角色窗口和气泡窗口截图组合，不包含用户桌面。

多显示器、混合DPI和真实休眠唤醒未硬件实测，继续沿用已有Qt逻辑坐标处理。本次没有重新生成或改动角色素材。

# 全部七图切换

按最新要求，时间规则只决定启动初始图片：普通时段普通图、午睡/夜间睡眠为睡觉图、晚间为深夜偏好图。

启动后，双击和周期轮播都遍历统一清单中的全部7张。每轮无重复，下一轮不立即重复上一张；从任意初始图开始，连续7次切换均覆盖全部7张。移除了每秒检查时段强制纠正图片的回调，手动选择不会立即被改回。

时间问候、睡眠免打扰、五分钟时钟、气泡关闭不切图、拖拽、身体动画等保持原有逻辑。时间问候继续按本地时间；深夜选中普通图不会解除时间上的问候免打扰。

本次验证：59项测试通过。真实Qt双击在白天、午睡、晚间和夜间睡眠均遍历七张；周期轮播在夜间也遍历七张；跨时间边界不覆盖当前图；启动初始图片仍按时间选择。原气泡关闭、计时、文案及交互回归通过。使用可控时钟验证周期，未实际等待五分钟。

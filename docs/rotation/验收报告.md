# 时间问候、图片轮播与气泡关闭修复

## 触发链与修复

原实现有提醒临时强制普通图、关闭气泡撤销提醒姿态、跨时段/设置保存清空手选图片、双击附带随机关怀语等相互耦合的路径。原双击代码虽然列出4/6张图，却没有独立轮次记录；这些覆盖和重置会干扰当前图片，不能仅靠调整两个图片下标修复。

现在仅周期轮播和桌宠双击推进基础图片；当前图片违反时间限制时，可立即纠正一次，记录 `time-rule-correction`。周期与时间纠正恰好同时发生时，只纠正一次。普通时间边界保持合法当前图片。启动依据当前时段初始化；深夜偏好只决定初始图/纠正目标，不限制轮播集合。

| 模块 | 职责 |
|---|---|
| companion_config.py | 全部素材ID及时间资格、四条原创、旧关怀语分类、主/辅助轮播规则、图片完整轮次 |
| schedule.py | 本地时间判断、唯一周期到期时间、文案进度、旧配置无损迁移 |
| desktop_pet.py | 到期协调、图片切换原因、重要消息排队、睡眠问候延后 |
| care.py | 气泡显示/隐藏/关闭、跟随与滚动；活动计时不再随机抽文案 |
| settings_ui.py | 时间、间隔、免打扰、独立主文案/辅助文案编辑 |

旧10秒关怀计时器已移除，由现有单一1秒调度器检查30分钟连续使用提醒。动画帧计时器、气泡跟随计时器和8秒自动隐藏计时器各司其职，不生成额外问候或轮播。任务/错误信息留在功能消息队列，不进入辅助文案池。已有离线气泡、拖拽、菜单、设置、活动提醒、身体与整图动画继续使用；自由聊天此前已移除，本次没有新增网络聊天或语音。

## 四条固定主文案（原文）

早上：早上好呀 新的一天，我陪着你。

中午：中午好～ 睡醒也要记得好好吃饭。

下午：下午好呀～ 除了上课健身也要注意安全。

晚上：晚上好哦～今天辛苦咯，I'm here 随时都在。

启动或新时段首次正常展示，先出主文案；之后「主→辅助A→主→辅助B」。辅助文案按配置顺序循环，去重但不改写，只有一条时可重复，没有辅助时重复主文案。旧普通问候、十条关怀语及原睡眠轻柔反馈均已保留并分类；旧自定义内容、未知字段、greeted历史保留。迁移不主动改写磁盘配置；用户保存设置时备份 `.json.bak` 后原子写入。

编辑入口：右键 → 陪伴与时间设置 → 时间问候。表格包含「辅助文案」「主文案」两列；辅助用「｜」分隔，允许留空。间隔默认5分钟，沿用可调间隔。打开/关闭设置、双击和关气泡不重置到期时间；调整间隔从下一个正常周期起应用。

## 气泡关闭与排队

气泡「×」只隐藏气泡、丢弃待发问候并抑制旧队列自动弹回，直到下一正常周期；不调用图片/文案选择，不改变动画或截止时间。已有功能消息保留在队列，不删除；新到达的重要提醒仍可打断抑制。自动超时不改变基础图片或轮播进度。气泡内鼠标事件被窗口接收，不传给桌宠。

五分钟到期时按最新时间推进图片，并仅保留一条当前问候；重要消息显示期间延后文案，不积压多轮。文案仅在实际显示时推进。休眠恢复只消费当前一次到期，不补播错过的轮次。睡眠期间非必要问候延后到主动单击或睡眠结束，双击不会借第一下点击额外推进问候。

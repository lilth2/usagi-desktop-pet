# 跟随气泡与周期问候

默认每5分钟问候一次，启动时一次。单一现有1秒调度器根据单调时钟判断间隔；跨时段、唤醒不会补发或连发。旧greeted记录保留但不再参与限制。旧原厂单条文案扩为两条，自定义文案保持原样。睡眠外观仍延迟到互动或睡醒，重要消息优先，待发问候仅一条。

设置：右键 → 陪伴与时间设置 → 陪伴（自动时间问候开关）；时间问候（间隔1–1440分钟、文案、跨午夜免打扰）。默认免打扰关闭。06–11早上好、11–14中午好、14–18下午好、18–06晚上好。

气泡显示8秒，右上角关闭，可滚动长文。随窗口Move/Resize事件立即重定位，50ms兜底检测隐藏、菜单和屏幕可用区变化。按Qt逻辑全局坐标和桌宠所在屏幕availableGeometry避开任务栏；优先上方，再右、左、下。菜单打开暂时隐藏气泡，关闭后恢复剩余显示时间。身体摇摆不会影响锚点。气泡无键盘焦点，关闭按钮和滚动区域可点击。

验证：39项本地测试通过，包含真实Qt窗口移动跟随、屏幕边缘、长文滚动、隐藏恢复、关闭按钮、周期300秒边界、不连续重复、跨午夜免打扰、消息优先级及原功能。跨显示器与混合DPI采用Qt逻辑坐标实现；没有多显示器硬件，未实际验证。真实休眠唤醒未实测。

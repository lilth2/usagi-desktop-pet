# 跨平台安装包 1.0.0

完整离线包已生成在本机deliverables目录，每个分发ZIP均包含安装程序/DMG、中文HTML和TXT使用说明、验证报告及SHA256SUMS。安装后无需Python或开发环境。

| 文件 | 用途 | 大小 |
|---|---|---|
| ChiikawaPet-Mac-AppleSilicon-1.0.0.zip | 苹果M系列；内含arm64 DMG，拖入应用程序 | 约37MB |
| ChiikawaPet-Mac-Intel-1.0.0.zip | Intel苹果；内含x86_64 DMG，拖入应用程序 | 约41MB |
| ChiikawaPet-Windows-1.0.0.zip | Windows10/11 64位；内含中文安装向导 | 约46MB |

Mac的DMG内部也有说明书，.app的Contents/Resources中另有一份；Windows安装后说明书位于程序目录，并提供开始菜单入口。Windows默认仅为当前用户安装，桌面快捷方式可选，提供正规卸载器，卸载不删除个人设置。

## 实际验证

- Windows 11：66项源码测试通过；新单文件程序自检成功；实际静默安装→安装后程序自检→卸载均退出0；HTML/TXT随安装写入；程序卸载后个人配置文件哈希保持一致。
- Apple Silicon：GitHub macos-15 arm64环境（macOS15.7.9）构建.app/DMG/ZIP并完成应用启动自检，七图遍历、身体帧加载、关怀气泡、关闭不换图、独立轮播计时、打开设置、CoreGraphics空闲时间读取均通过。
- Intel：GitHub macos-15-intel x86_64环境（macOS15.7.9）完成相同构建和启动自检并通过。
- macOS两个架构均通过codesign深度完整性检查；下载产物的SHA256与云端构建一致；原生Mach-O架构与目标一致；使用说明正文与本地源文件一致（仅允许系统换行差异）；最终分发ZIP完整性检查通过。
- Mac使用系统CoreGraphics读取空闲秒数，无需第三方输入记录服务；Mac新设置位于Library/Application Support/ChiikawaPet，已有~/UsagiPet配置继续沿用。Windows原路径不变。

构建记录：https://github.com/lilth2/usagi-desktop-pet/actions/runs/39255687336

这是个人分发版本：Windows没有购买发行者签名；Mac采用ad-hoc完整性签名，没有Developer ID及Apple公证。Mac首次打开可能需在系统设置→隐私与安全性中确认“仍要打开”，说明书附Apple官方步骤。不关闭系统安全保护。

没有用户实机上的多显示器、混合DPI、睡眠唤醒或旧macOS系统测试。macOS构建目标为11及以后，实际启动验证仅在15.7.9；不将目标版本写成已实测兼容所有版本。Windows测试不是全新无开发环境虚拟机，但分发包确实包含Python/Qt运行时及全部角色资源。

## 重建

Windows先运行build.ps1，再用Inno Setup编译packaging/windows.iss。macOS可在GitHub Actions手动触发Build macOS installers；两个架构并行原生构建，产物保留30天。源码和工作流已推送，最终ZIP在本机保存，不依赖Actions保留期限。

包内完整用户说明源文件：packaging/使用说明.html与使用说明.txt。
